# Study sessions replace planned blocks

The app no longer schedules planned blocks or imposes an evening restriction for an incomplete plan. A study session started on Android or Chrome is the only event that activates phone app restrictions and Chrome site blocking. This removes a second, time-based source of enforcement while preserving the daily study target for reviews and the reminder to begin a study session. Legacy block fields may remain in stored version 1 snapshots for compatibility, but clients ignore them and the sync API discards them.
